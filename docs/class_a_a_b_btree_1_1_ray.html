Detailed Description

template<std::floating_point Real, Integer N>
class AABBtree::Ray< Real, N >

Forward declaration of the Ray class template.

Template Parameters
RealType of the scalar coefficients.
NDimension of the ambient space.

This class represents a ray defined by an origin point and a direction vector. The ray is the set of points \( \mathbf{o} + t\,\mathbf{d} \) with \( t \geq 0 \). The class provides functionality for:

  • Ray transformations (translation, rotation, scaling);
  • Distance computations to points and boxes;
  • Intersection tests with axis-aligned bounding boxes;
  • Normalization and comparison operations.
Template Parameters
RealFloating-point scalar type (must be float or double).
NDimension of the ambient space.
Note
The direction vector is not required to be normalized.

◆ minimize_over_ray()

template<std::floating_point Real, Integer N>
Real AABBtree::Ray< Real, N >::minimize_over_ray ( Box const & b,
DistanceKind const kind ) const
inlineprivate

Find the ray parameter \( t \geq 0 \) that minimizes the squared distance between the ray point \( \mathbf{o} + t\,\mathbf{d} \) and the box (closest or farthest box point, depending on kind).

Along each axis the squared distance is a convex, piecewise quadratic function of the coordinate:

  • interior: \( \max(0,\, m - x,\, x - M)^2 \), with breakpoints at the box faces \( m \) and \( M \);
  • exterior: \( (|x - c| + h)^2 \), with a breakpoint at the box center \( c \) ( \( h \) is the half size).

Substituting \( x = o + t\,d \), the sum over the axes is a convex, piecewise quadratic function of \( t \). Between two consecutive breakpoints it is a single quadratic \( A t^2 + B t + C \), whose minimum on the interval is found in closed form. The smallest of these minima is the exact global minimum.
