Detailed Description

template<std::floating_point Real, Integer N>
class AABBtree::Tree< Real, N >

The Tree class provides an efficient way to store and query a set of axis-aligned bounding boxes non-recursively. It supports various operations such as building the tree, adding axis-aligned boxes, and performing intersection queries. The Tree class is templated on the type of the real numbers and the dimensions of the bounding boxes and is based, as the name suggests, on a novel non-recursive algorithm.

How the tree is organized

  • The boxes are owned by the tree (m_boxes_ptr) and never moved: queries report their original indices. m_tree_boxes_map is a permutation of these indices such that every node owns a contiguous range of it, starting at box_ptr and box_num long.
  • A node is split along one axis: the boxes entirely on the left (right) of the separation line go to the left (right) child, while the boxes crossing it, called long boxes, stay in the node. So every node stores its long boxes (bounded by box_long), and a leaf stores all its boxes as long boxes (and box_long is equal to box).
  • All the traversals use explicit stacks, never recursion.
Note
Thread safety: once the tree is built, all the const methods can be called concurrently from multiple threads. The query statistics returned by stats() refer to the last completed query (or batch of queries).
With OpenMP support (_OPENMP defined) build, the *_batch methods and the tree-tree queries (intersect(Tree), self_intersect and distance(Tree)) run in parallel. The tree built does not depend on the number of threads. The number of threads is set with num_threads (1 disables parallelism). Tree-tree queries run serially when called from inside a parallel region or when the trees have fewer than AABBTREE_PARALLEL_MIN_NODES nodes in total. Results do not depend on the number of threads.

◆ dual_traversal()

template<std::floating_point Real, Integer N>
template<typename Result, typename Step, typename Merge>
void AABBtree::Tree< Real, N >::dual_traversal ( Tree< Real, N > const & tree,
Result & result,
Workspace & ws,
Step && step,
Merge && merge ) const
inlineprivate

Traverse pairs of nodes of this tree and of another tree, starting from the pair of roots. step(ref_1, ref_2, result, workspace, stack) processes a pair of node references and pushes the pairs to visit next on the stack.

With OpenMP the traversal is first expanded breadth-first until enough independent pairs are available, then the pairs are processed in parallel, each one with its own partial result. Partial results are merged in a fixed order with merge(dst, src), so the result is deterministic.

Near && near,
Visit && visit ) const
inlineprivate

Visit the pairs made of a long box of node_1 (this tree) and a long box of node_2 (the other tree).

The boxes of the node with fewer long boxes are visited in the outer loop and, as a cheap pre-filter, each of them is first tested against the bound of the long boxes of the other node: if near(box, other_box_long) is false, the inner loop is skipped. visit(pos_1, box_1, pos_2, box_2) is then called for each pair.
